# Mystery Documentary Factory

Reusable production system for evidence-based documentary YouTube Shorts.

- Audience: United States / international.
- Public narration & SEO: English (US). Production coordination: Bahasa Indonesia.
- Target duration: 75–120 seconds; final length follows approved audio and SRT.
- Formats: 9:16, internet-first licensed media, selectively generated AI visual assets, HTML motion graphic, and MP4.
- Every episode progresses through STEP 00–11 using explicit PASS/FAIL/BLOCKED gates.
- Narration, visuals, and pilot HTML require explicit approval at the applicable gate.
- AI image assets **must not be generated without the user's explicit permission**; prompts are delivered as standalone TXT.
- Actual allegations must be distinguished from established facts; cite source evidence.

## Repository workflow

Keep reusable templates under `templates/EPISODE_STARTER/`. Copy them for every episode using a new `EPxxx` identifier. Keep media and personal data out of git until appropriate license and privacy checks pass.

This repository currently holds the project framework. No episode is automatically approved or published by placing files here.
